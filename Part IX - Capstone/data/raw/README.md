## Workbook Structure

The workbook contains one worksheet named `Online Retail`.

It contains 541,910 rows and 8 columns, including one header
row. Therefore, the actual number of data records is 541,909.

## Data Preservation

The original workbook must remain unchanged.

All analysis and derived datasets must be stored separately.

The original Excel file is intentionally excluded from Git.
It can be obtained from the official UCI source.

## Important

The Excel workbook's file modification timestamp is not treated
as the dataset's original publication date or the project's
verified download date.
